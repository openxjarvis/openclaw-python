# 工具详细对比

## 1. 错误处理机制

### TypeScript
- ToolInputError (status: 400) - 参数错误
- ToolAuthorizationError (status: 403) - 权限错误
- OWNER_ONLY_TOOL_ERROR - 仅所有者工具

### Python  
- ❌ 无专门的错误类
- 使用 ToolResult(success=False, error="...")
- 无法区分 400 vs 403 错误

## 2. 工具参数验证

### TypeScript
```typescript
// 使用 TypeBox 进行强类型验证
parameters: Type.Object({
  task: Type.String(),
  timeout: Type.Number({ minimum: 0 }),
  ...
})

// 运行时验证
readStringParam(params, "task", { required: true });
readNumberParam(params, "timeout", { min: 0 });
```

### Python
```python
# 使用 JSON Schema
{
    "type": "object",
    "properties": {
        "task": {"type": "string"},
        "timeout": {"type": "number", "minimum": 0},
    },
    "required": ["task"]
}

# 运行时手动验证
task = params.get("task")
if not task:
    return ToolResult(success=False, ...)
```

## 5. Image 工具对比

### TypeScript 参数
```typescript
{
  prompt?: string,
  image?: string,     // 单个图像
  images?: string[],  // 多个图像（最多 20）
  model?: string,
  maxBytesMb?: number,
  maxImages?: number,
}
```

### Python 参数
```python
{
  "image": string,     # 必需
  "prompt": string,    # 必需
  "model": string,
}
```

**差异**:
- ❌ Python 缺少 `images` 数组参数（多图像支持）
- ❌ Python 缺少 `maxBytesMb` 参数
- ❌ Python 缺少 `maxImages` 参数
- ⚠️ Python 将 prompt 设为必需，TS 为可选
